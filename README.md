# Lattes Assist v1.6 — Identidade Persistente de Registros

Novidades:
- chaves estáveis internas derivadas de atributos substantivos;
- prioridade para DOI, ISBN, ISSN, títulos, nomes, instituições e anos;
- fallback por posição apenas quando não há atributo substantivo;
- relatório de cobertura de identidades estáveis;
- diff semântico menos sensível à reordenação dos nós;
- exportação do relatório de identidade junto ao diff semântico.

As chaves persistentes não são gravadas no XML do Lattes; existem apenas no Lattes Assist para correspondência entre versões.
